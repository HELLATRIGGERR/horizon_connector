# UI and item interaction parity ledger

Reference: Applied Energistics 2 19.2.18, commit `db17504a86128fdf3dae31f5fb7a112a646e0b93`. Source names below are under `src/main/java/appeng/` in that revision. Native paths are relative to `ludovic111-horizon-7f8a668/crates/horizon-client/src/` unless otherwise stated. This is a feature-family inventory, not a claim that every gesture, extension or version combination has been audited.

**Implemented** means a corresponding native path exists. **Historically exercised** refers to the bounded checkpoint checks described in [STATUS.md](STATUS.md), not a test of the current working tree. **Pending** identifies missing functionality or a behavior whose current implementation still needs a specific end-to-end comparison. Registered content, generated assets, helper tests and code paths alone do not establish parity.

## Cross-cutting gaps

- The default server-thread route has substantially more coverage than in-frame. The Provider, local terminal and confirmation paths and selected physical machine menus have passed focused in-frame fixtures; one earlier Provider-related network-readiness failure did not recur and remains a timing observation. The in-frame Import Bus and both Level Emitter menus passed bounded physical cases on Wave 15, and Pattern Access passed a physical transfer/restart case on Wave 16. Other in-frame menus and broader action combinations still need implementation or independent verification.
- `WrappedGenericStack.overrideOtherStackedOnMe` is implemented for ordinary player and generic-container menus, including component-free water/lava bucket exchange. The [physical custody fixture](../tests/world/wrapped-player-inventory.ts) passed on the Wave 8 server-thread binary for two bucket fills across restart and the ME terminal player slots. Machine player-slot handling passed a Workbench test for wrapped conversion on Wave 9, but that fixture used a creative clone which `AEBaseScreen.slotClicked` forbids.
